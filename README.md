# 🎞️ SANDYS101.IN — Warm Analog Journal & Personal Viewpoint

A distinguished, responsive, high-performance personal viewpoint website designed for instantaneous deployment on **GitHub Pages** (with custom domain `sandys101.in`).

Built with pure **HTML5**, **CSS3 (Warm Analog Journal Design Tokens)**, and vanilla **JavaScript (ES6+)** with **zero build step or external dependencies required**.

---

## ✨ Features

- 🌓 **Warm Walnut & Antique Parchment Theme**: Built-in toggle with automatic system theme detection and `localStorage` persistence.
- 🖼️ **Interactive Exhibition Photo Lightbox**: Click any photograph plate to inspect it in full-screen with authentic film frames, EXIF data, and keyboard controls (`Esc`, `←`, `→`).
- 🧭 **In-Page Editorial Navigation & Scroll Spy**: Dynamic masthead highlighting the active section (`01 Manifesto`, `02 Visual Pursuits`, `03 Darkroom Kit`, `04 Nocturnal Ops`).
- 🔍 **Calibrated Optical Spectrum Infographic**: Interactive focal length spectrum illustrating the 33mm prime lens "human eye" perspective and zoom coverage.
- 📊 **Nocturnal Command Ledger**: Operational metrics dashboard and operational duality comparison ("Behind the Shutter" vs "On the Operations Floor").
- 📱 **Fully Responsive**: Mobile-first editorial layout looking sharp across smartphones, tablets, and ultra-wide displays.
- ⚡ **Zero Build Step**: Native static files ready to be hosted directly on GitHub Pages.

---

## 🚀 How to Deploy to GitHub Pages

1. In your terminal inside this repository folder, run:
   ```bash
   git add .
   git commit -m "Transform look and template into Warm Analog Journal"
   git push origin main
   ```
2. Your website will be live automatically at **`https://sandys101.in`** (or `https://sandys101.github.io`).

---

## 💻 Local Preview

You can open the website locally anytime:
- Double-click `index.html` in your file explorer to open it in your browser.
- Or use Python's built-in static server:
  ```powershell
  python -m http.server 8000
  ```
  Then open `http://localhost:8000` in your web browser.
