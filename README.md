# 📷 SANDYS101.IN — Modern Condensed Portfolio & Personal Viewpoint

A modern, high-density personal viewpoint and photography website designed for instantaneous deployment on **GitHub Pages** (with custom domain `sandys101.in`).

Built with pure **HTML5**, **CSS3 (Modern Condensed Architecture)**, and vanilla **JavaScript (ES6+)** with **zero build step or third-party dependencies required**.

---

## ✨ Features

- 📝 **Investigative Consumer Dispatches**: Dedicated long-form investigative reports (e.g. *Tata Service Center Petrol Leak Hazard Breakdown* at `tata-service-center-hazard.html`) with WhatsApp transcripts, financial audit tables, and evidence exhibits.
- ⚡ **Modern Condensed Theme**: Ultra-clean high information density layout with tight spacing, sleek micro-borders, and high-impact visual typography.
- 🖼️ **Curated Photography Gallery**: 6 genuine photographs by Sundeep (`photos/`) covering lake horizons, midnight monuments, 12th-century heritage, wildlife, temples, and mountain expedition camps.
- 🔍 **Interactive Full-Screen Lightbox**: Click any photo plate to inspect with high-definition display, EXIF telemetry, and keyboard navigation (`Esc`, `←`, `→`).
- 🌓 **Dark & Light Mode**: Built-in toggle with automatic system theme detection and `localStorage` persistence.
- 🧭 **In-Page Scroll Spy Navigation**: Active section tracking highlighting current section in a compact 60px header.
- 📊 **Nocturnal Command Ledger**: Operations metrics dashboard (-20% escalations, +15% output, 99.8% SLA, AI QA automated audits) and operational duality spread.
- 📱 **Fully Responsive**: Mobile-first architecture optimized for all smartphone, tablet, and desktop viewports.
- ⚡ **Zero Build Step**: Pure static native files ready to run directly anywhere.

---

## 🚀 How to Deploy to GitHub Pages

```bash
git add .
git commit -m "Transform to modern condensed theme with curated photos gallery"
git push origin main
```
Your website will be live automatically at **`https://sandys101.in`** (or `https://sandys101.github.io`).

## 🔍 SEO & Google Analytics Configuration

### 1. Google Analytics 4 (GA4) Setup
The website is equipped with Google Analytics 4 (gtag.js) support and custom interaction tracking (theme toggles, lightbox image views, and outbound link clicks).

To connect your GA4 account:
1. Open [`index.html`](index.html) and [`tata-service-center-hazard.html`](tata-service-center-hazard.html).
2. Search for `G-XXXXXXXXXX` and replace it with your real Google Analytics 4 Measurement ID (e.g., `G-1A2B3C4D5E`).

### 2. Search Engine Indexing & Sitemaps
- **Sitemap**: Generated at [`sitemap.xml`](sitemap.xml) with Google Image tags so all curated photographs appear in Google Images search.
- **Robots**: Configured at [`robots.txt`](robots.txt) allowing search engine crawlers with direct pointer to the sitemap.
- **Schema.org**: Embedded JSON-LD structured data (`WebSite`, `Person`, `ImageGallery`, and `Article`) for rich snippets and Google Knowledge Graph optimization.
- **Social Previews**: Open Graph and Twitter Card tags configured with high-res image previews for WhatsApp, LinkedIn, X, and Facebook sharing.
